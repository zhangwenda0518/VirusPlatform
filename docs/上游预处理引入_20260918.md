## 3. ⚠️ 重要发现：**四套「日期→小数年」口径**（只报不改，等你拍板）

同一份数据能算出不同答案 —— 这正是上游当年建 `decimal_year.py` 的原因，
而我们平台**又有四处**（实测）：

| 数据 | `phylodyn_local.to_decimal_year`（**A0 全链在用的**） | `phylodyn_kit.date_to_decimal` | `virphykit_export.decimal_year` | 上游 `decimal_year` |
|---|---|---|---|---|
| `2013-05-01` | 2013.375 | 2013.3313 | 2013.3288 | **2013.3333** |
| `2013-05` | 2013.375 | 2013.3696 | 2013.3288 | **2013.3709** |
| `2013` | **2013.0**（年初） | **2013.5366**（年中） | **2013.0** | **2013.4556**（6-15） |

- 差异最大的是「只给年」：**2013.0 vs 2013.5366，差 0.54 年** —— 对以年为尺度的定年不是小数。
- 而「只给年」在你的数据里**有 210 行**（`Collection_Date` 只到年的那些）。
- 新模块 `phylodyn_govern.decimal_year(raw, mode)` 已经给出**唯一实现**并把 `mode`
  （`mid`＝年中 / `start`＝年初）**显式暴露**，与上游逐条对拍一致 → **下一步只需把消费方切过来**。
- ❗ **我没有改 A0 的数值行为**：切过去会让"只给年"的行整体后移最多 0.5 年，
  已跑过的结果与新的不可直接比较。**要不要切、按哪个 mode，请你定**（建议 `mid`，与上游和 BEAST 侧一致）。

## 4. 本轮落地内容

### 4.1 新模块 `phylodyn_govern.py`（元数据入口治理）

- `is_placeholder(v)`：字面量 + 5 条**精确**正则（`YYYY-MM-DD` / `YYYY-MM` / `YYYY` /
  `XX.XX N XXX.XX E` / `Country:Region`）。⚠️ 只精确匹配：上游曾用泛化正则误伤真实地理 72 条。
- `parse_date(raw, mode='mid'|'start')`：7 种格式（ISO 三档 / `DD-Mon-YYYY` / `Mon-YYYY` /
  `DD/MM/YYYY` / `DD.MM.YYYY` / 小数年），**小数年消歧判据＝小数位 ≥4**（`2014.05` 是"年.月"）。
- `parse_location(raw, drop_unknown=True)`：**冒号也拆**；删 `Unknown` 层级并留痕；
  删完只剩国名 → `country_only`（**不赋国家中心点**）。
- `govern_rows()`：逐行记账（`issue`/`precision`/`fmt`/`dropped_levels`），**只清空字段不丢行**。
- 三条原则写死在模块头：**不猜、不静默、不改语义**。

### 4.2 新模块 `phylodyn_alignqc.py`（比对 QC）

- 逐序列 长度 / gap% / 简并字符% / identity（对指定参考或**多数票共有序列**）；
  判定 `too_short` / `too_gappy` / `too_ambiguous` / `identity_low`。
- 额外给**「是否等长」**（A0 的硬前置）；落盘 `align_qc_report.tsv` + `clean.fasta` + `removed.fasta`。
- `align()` 复用平台 `phylo._run_mafft`（已处理中文路径 ASCII 中转 + 体量降级）。

### 4.3 接进数据准备链（顺序有讲究）

```
导入校验 → 治理（默认开）→ 三元组去重（可选）→ 比对 QC / 先 MAFFT 再 QC（可选）
        → 区域坐标表（可选）→ 时空降采样（可选）→ 概览汇总
```
- **治理必须在校验之前**（在 `import_from_files/_sniff_table_text` 内跑）：否则
  `DD-Mon-YYYY` 这种行会在 import 阶段就被严格校验剔掉、根本轮不到归一。
- 去重按 (date, location, sequence)；⚠️ **地点为空的行不参与去重**（治理会把 `Unknown`
  清空，若拿空地点当键，不同国家的记录会被当重复删掉 —— 那是"猜"）。
- QC 之后**一律以干净集交付**（否则交付集与 A0 看到的不是同一批样本）。
- 新增卡片开关：治理 / 去重 / 「允许没有地点」/ QC 三选一；结果面板显示三步报告。

## 6. 一个行为变化，必须告诉你

「**438 条**」（`Unknown` 的行因"缺地点"被剔除）。这不是 bug：
`Unknown` 当区划去参与时空调度/降采样本身就不可靠（我们之前还专门为它加过防护）。
