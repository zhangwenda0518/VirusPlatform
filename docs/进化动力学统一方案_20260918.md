### 本轮踩到的坑（写在这里，后人别再撞）
**A. 批量删多个 `<section>` 时区间会重叠 1 行**：用「第一个 `</section>`」当区间尾，
相邻卡区间首尾重叠；按 offset 倒序删的前提是区间互不重叠，于是每对多吃 1 行
—— 实测吃掉了 `t-dsrna` 前的 HTML 注释首行，`_it_platform.py` 报
"t-dsrna 不是 `<main>` 直接子卡片"。修法：区间尾用
**「下一个 `<section` 之前的最后一个 `</section>`」** + 断言区间互不重叠 +
删除后行数正好等于 Σ区间行数。另：这份 HTML 缩进是**混的**（`t-pdrand`
开标签缩进 4 空格，它的 `</section>` 却缩进 2 空格）→ **别靠缩进匹配**。

**B. `_it_platform.py` 第 5 节是过期断言**：它断言 `/api/explorer/*` **存在且非 404**，
而该蓝图 09-17 已整体摘除 → `check()` 内的 `assert` 让文件在第 5 节就崩、
后面 100+ 条检查一条都跑不到，看起来像本次改坏的。已改成**反向断言（必须 404）**，
`/reference/i18n.js` 一并纳入。

**C. ★ 移植对拍不能带前缀过滤**（本轮最大的教训）：前两轮对拍写了
`^(pd|_dyn|PD_)` 前缀过滤，于是漏掉
`const PD_STAGES`（**常量**，函数级对拍天生查不到）与 `drawTimeTree`（**不带前缀的函数名**），
两次都是跑任务/浏览器才炸出来。改用 `run/_zz_port_missing.py`：**不设前缀**，
把移植块里所有"自由调用标识符"（排除 `.foo(` 方法、字符串、局部变量）逐个对拍到零缺失。

**D. ★ 移植后必须跑任务层测试**：`import time` 缺失（→ `NameError`）、`PD_STAGES`、
`drawTimeTree` **三处漏搬全部**是 POST `/api/tool/run` 的任务层测试抓到的 ——

## 9. 追加：explorer **新版导出（25 列）**支持 —— 列名归一化 + 自动择优（2026-09-18 03:20）

用户给的实情：**explorer 现在不导出 zip 了**，新版 metadata 是 25 列，

`Collection_Date`↔`Release_Date`、`Geo_Location`↔`Country` 各有一个可能为空。
用户口径原话：「**哪个不空、哪个详细、哪个早，用哪个**」。

**改造前：不支持** —— `_sniff_table_text` 硬要求 `name,date,location` → 整表被拒。

### 实测数据形状（PSTVd 档，2,967 条）

| 列 | 有值率 | 形态 |
|---|---|---|
| `Release_Date` | **100%** | 全 day；跨度 1982–2024 |
| `Collection_Date` | 12%（357） | year 210 / month 106 / day 41；跨度 1978–2023 |
| `Geo_Location` | 14.8%（438） | **58 条带冒号**（`Russia: Stavropol` 省级），其余仅国名 |
| `Country` | 14.8%（438，**同一批行**） | 与 Geo 仅 59 条不同（Geo 多出省州） |
| `Year` | 100% | 有采集年用采集年、否则用发布年 |

### 择优口径（`phylodyn_kit.py`，两个入口共用）

- **日期**：`collection_date…`（采样类，既"更早"又语义正确）→ 空则 `release_date…`
  → 再空退 `year…`；组内多个非空取**最早**。
  ⚠️ **退用发布日 = 时间轴整体偏晚** → 逐行记账 + summary/前端告警（实测触发 2,610 行）。
- **地点**：`geo_location…`（含冒号/更长＝更详细）→ 空则 `country…`。
  ⚠️ `Unknown` 只当"没信息"来让位，**两列都 Unknown 时原样保留** ——
  否则本样本会从 2,967 行掉到 438 行，且与历史行为不一致。
- API：`meta_pick_date` / `meta_pick_location` / `meta_pick_name` / `normalize_meta_rows`。
