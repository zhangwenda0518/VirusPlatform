## 三、修复清单

### A. 结果可信度（错误结论 / 不可解释结论）

**A1 ⚠严重｜⑧引物宿主特异性：`host_hit` 恒为 `NO`（错误结论）**
- 位置：`Virus_Platform_Core/primer.py`
- 问题：`amplicons.fa` 写入的是"左臂+右臂反向互补"约 40bp 占位串，而
  `check_specificity_blast` 的命中判据是 `比对长度 >= 100`——占位串物理
  上不可能 ≥100bp，于是**每一对引物都被判成"宿主无命中"**，而该列被当作
  特异性结论展示。
- 修复：
  - `design_primers_for_seq` 新增 `amp_seq` 字段：用 primer3 的
    `amp_start/amp_end`（1-based，均落在模板上）从模板截取**真实扩增子**
    （`primer.py:54`、`primer.py:82`）；
  - `design_primers` 写 `amplicons.fa` 时优先用真实扩增子，退化为占位时
    逐条计数并 WARN，summary 记录 `specificity_amplicon ∈ real/mixed/placeholder`；
  - 命中判据改为按查询长度自适应 `比对长度 >= min(100, 查询长度)`，
    长扩增子沿用 ≥100bp 实质命中口径，短占位串要求整段命中
    （`primer.py` `check_specificity_blast`）；
  - 检查完成后输出一行汇总（命中数/占比），失败日志带异常类型。
- 验证：合成模板探针——`amp_seq` 长度恰等于 `product` 且为模板子串
  （844/843/843）；隔离 BLAST 端到端——真实扩增子与 40bp 占位串均能命中
  造进假宿主基因组的对应片段，阴性对照 300bp 随机串正确不命中。

**A2 ⚠严重｜③c 共识：超短 reads 会被读成"病毒不存在"**
- 位置：`Virus_Platform_Core/consensus.py:68`、`:563`、`:651`
- 问题：minibwa（minimap2 内核）对 <30bp reads 实测比对率为 0。小RNA/siRNA
  样本走 ③c 时，覆盖度为 0 **不是**"样本里没有该病毒"，而是"引擎测不到"；
  旧实现直接按阈值判 `present='no'`。
- 修复：新增 `MINIBWA_MIN_READ_LEN=30` 与 `_probe_read_len()`；命中超短
  条件时先把全部 contig 置 `present='unknown'`（并 WARN 说明"不代表不存在"），
  summary 增 `unsupported_short_reads` / `max_read_len_sampled` / `unknown` 列表。
- 验证：读长嗅探探针（FASTQ/FASTQ.gz/FASTA/折行 FASTA/空文件/二进制垃圾文件）；
  双端取最大语义（一端正常即不判超短）。

**A3 ｜②b 鉴定：物种数被 0 计数参考行灌水（虚高上百倍）**
- 位置：`Virus_Platform_Core/kv_stage.py:203` `_summarize`
- 问题：minibwa 走 `samtools idxstats` 口径，对库内**每条参考**都出一行
  （含 0 计数）。旧实现把 0 计数行也算进 `species_detected`。
- 证据（真实产物 `run/tool_runs/kvsuite_20260914_135927_abdc4d`）：
  8464 行中 8461 行 0 reads → 旧口径"检出 5816 个物种"，实际只有 3 个。
- 修复：reads=0 的行只进 reads 求和、不进物种名单；读数列无法解析时保守
  计入（不据此判未检出）。

**A4 ｜②b 定量：salmon 的"片段"被当成"read"再除以 2**
- 位置：`Virus_Platform_Core/kv_stage.py:408`
- 问题：`viral_pairs = reads // 2 if r2 else reads` 不分引擎。salmon 的
  `NumReads` 是**片段**数（PE 一对=1），minibwa 是映射记录数（PE 一对=2）。
  salmon+PE 样本的"病毒 reads 对数"被腰斩一半，可能误触发 ③组装的
  `min_viral_pairs` 门槛（默认 500）并误导判断。
- 修复：按引擎归一 `reads_unit ∈ fragments/reads` 与 `viral_pairs`，
  summary 同时记录口径，完成日志改为"病毒 N fragments（≈M 片段/对）"；
  GUI 阶段摘要（中/英 `_sum_kvsuite*`）同步显示单位，老结果无
  `reads_unit` 字段时按 `engine` 回推（salmon→片段），不误标。

**A5 ｜⑥ORF：`min_orf_aa` 只作用于 orfipy，不作用于 pyrodigal**
- 位置：`Virus_Platform_Core/orf.py:143`、`:170`、`:282`
- 修复：pyrodigal 走 `min_gene = min_aa*3`（老版本无该参数时退回默认构造
  并按长度二次过滤 `dropped_short`），summary 记录 `min_aa`；未知工具名
  从"静默忽略"改为 WARN 并列出可用值。

**A6 ｜②b kvsuite 过滤段：空 DataFrame 兜底会写出"全部剔除"**
- 位置：`Virus_Platform_Core/known_virus_suite/known_virus_suite.py`
- 修复：识别段结果缺失时直接 `RuntimeError`（附可执行提示），不再用空表
  冒充过滤结论。
