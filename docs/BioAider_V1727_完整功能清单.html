本清单因此不以手册为据，直接以程序为准。

三、对上一轮建议的修正

上一轮我给的建议里，功能框架只覆盖了手册的七组，漏掉了 Clustering Analysis 整个分类， 也没有把底部工具栏那排（尤其 Sequence Editor）计入。补齐后，有 4 项需要重新评估：
新纳入考虑平台现状评估
K-mer 层次聚类 k-mer 只用于宿主比对（utils.py）和链方向判定（sdt_exact.py），无序列聚类工具 值得考虑。对 virome contig 分组、大序列集去冗余前的粗聚类有用；你们已有 MMseqs2，实现成本低
连锁突变位点（Mutation Analysis 的 Linked 模式） 零命中 值得考虑。准种 / 耐药突变研究里，位点连锁比单位点频率更有信息量
日期转十进制 零命中 看需求。如果做 tip-dating / 分子钟定年就需要，否则不必
蛋白定位回核苷酸 零命中 低优先。你们已有 cds_export / contig_annot，功能有部分重叠

其余结论不变：多基因串联 + 分区文件、参考集按 identity 去冗余、 序列 ID 重命名、模糊碱基校正、系统发育格式互转 仍是真缺口； examples/ 补参数说明仍是我认为投入产出比最高的一项。
