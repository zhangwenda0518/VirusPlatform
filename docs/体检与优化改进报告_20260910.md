## 1. P0（1 条）

### 1.1 `db-migrate` 引用不存在的符号 → 移动模式下数据已删、配置未切

- **证据**：`Virus_Platform_Core/db_migrate.py:186` 原文 `from .config import cfg`；`Virus_Platform_Core/config.py` 只有 `get_config()`，全仓无 `cfg` 导出。实测 `python -c "from Virus_Platform_Core.config import cfg"` → `ImportError: cannot import name 'cfg'`。
- **后果**：`python main.py db-migrate --to D:\db` 在**复制+校验+删源全部完成之后**才抛 ImportError（`--mode move` 时平台内 `databases/`、`host-db/`、`virus-db/` 已被 `shutil.rmtree`），`database_root` 仍为空 → 平台处于"无数据库"状态。
- **修复**：改为 `from .config import get_config` + `get_config().set_database_root(to_dir)`，异常兜底从 `(OSError, ValueError)` 扩到 `Exception`，返回结构化错误。
- **验证**：`tests/_verify_fixes.py` 断言 `Virus_Platform_Core.config` 不再有幽灵 `cfg`。
