## 六、方法说明

定位"exe 能启动但静默失败"的通用手法：

1. `subprocess.run` 取 returncode：`3221225781`（0xC0000135）直接判定缺 DLL
2. `ctypes.CDLL` 逐个加载同目录 DLL，命中首个失败项（比 Windows 原生报错精确）
3. 解析 PE 导入表（`DataDirectory[1]` → `_IMAGE_IMPORT_DESCRIPTOR`）列出直接依赖
4. 递归求传递闭包，与目录实际文件求差集 = 缺失清单

**两个坑**：
- `subprocess` 的 `cwd` 必须是 exe 所在目录，否则 DLL 搜索路径不含该目录 → 误判
- Git Bash 下 `/tmp` 是虚拟路径，Python 无法解析，须用 Windows 绝对路径
