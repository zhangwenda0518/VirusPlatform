[00;01mLSD: LEAST-SQUARES METHODS TO ESTIMATE RATES AND DATES - v.2.4.1

[00;01mDESCRIPTION
[00;00m	This program estimates the rate and the dates of the input phylogenies given some temporal constraints.
[00;00m	It minimizes the square errors of the branch lengths under normal distribution model.

[00;01mSYNOPSIS
[00;00m	[00;01m./lsd [00;00m[[00;01m-i [00;04minputFile[00;00m] [00;00m[[00;01m-d [00;04minputDateFile[00;00m] [00;00m[[00;01m-o [00;04moutputFile[00;00m] [00;00m[[00;01m-s [00;04msequenceLength[00;00m] [00;00m[[00;01m-g [00;04moutgroupFile[00;00m] [00;00m[[00;01m-f [00;04mnbSamplings[00;00m] [00;00m
[00;01mOPTIONS
[00;00m	[00;01m-a [00;04mrootDate
[00;00m	   To specify the root date if there's any. If the root date is not a number, but a string (ex: 2020-01-10, or b(2019,2020)) then it should
[00;00m	   be put between the quotes.
[00;00m	[00;01m-b [00;04mvarianceParameter
[00;00m	   The parameter (between 0 and 1) to compute the variances in option -v. It is the pseudo positive constant to add to the branch lengths
[00;00m	   when calculating variances, to adjust the dependency of variances to branch lengths. By default b is the maximum between median branch length
[00;00m	   and 10/seqlength; but it should be adjusted  based on how/whether the input tree is relaxed or strict. The smaller it is the more variances
[00;00m	   would be linear to branch lengths, which is relevant for strict clock. The bigger it is the less effect of branch lengths on variances, 
[00;00m	   which might be better for relaxed clock.
[00;00m	[00;01m-d [00;04minputDateFile
[00;00m	   This options is used to read the name of the input date file which contains temporal constraints of internal nodes
[00;00m	   or tips. An internal node can be defined either by its label (given in the input tree) or by a subset of tips that have it as 
[00;00m	   the most recent common ancestor (mrca). A date could be a real or a string or format year-month-day.
[00;00m	   The first line of this file is the number of temporal constraints. A temporal constraint can be fixed date, or a 
[00;00m	   lower bound [00;00m[00;04ml(value)[00;00m, or an upper bound [00;00m[00;04mu(value)[00;00m, or an interval [00;04mb(v1,v2)
[00;00m	   For example, if the input tree has 4 taxa a,b,c,d, and an internal node named n, then following is a possible date file:
[00;00m	    6
[00;00m	    a l(2003.12)
[00;00m	    b u(2007.07)
[00;00m	    c 2005
[00;00m	    d b(2001.2,2007.11)
[00;00m	    mrca(a,b,c,d) b(2000,2001)
[00;00m	    n l(2004.3)
[00;00m	   If this option is omitted, and option -a, -z are also omitted, the program will estimate relative dates by giving T[root]=0 and T[tips]=1.
[00;00m	[00;01m-D [00;04moutDateFormat
[00;00m	    Specify output date format: 1 for real, 2 for year-month-day. By default the program will guess the format of input dates and uses it for
[00;00m	    output dates.
[00;00m	[00;01m-e [00;04mZscoreOutlier
[00;00m	   This option is used to estimate and exclude outlier nodes before dating process.
[00;00m	   LSD2 normalize the branch residus and decide a node is outlier if its related residus is great than the [00;04mZscoreOutlier.
[00;00m	   A normal value of [00;04mZscoreOutlier[00;00mcould be 3, but you can adjust it bigger/smaller depending if you want to have
[00;00m	   less/more outliers. Note that for now, some functionalities could not be combined with outliers estimation, for example 
[00;00m	   estimating multiple rates, imprecise date constraints.
[00;00m	[00;01m-E
[00;00m	   Use this option if you want to estimate the rate of internal and external branches separately.
[00;00m	[00;01m-f [00;04msamplingNumberCI or bootstrapTreeFile
[00;00m	   This option calculates the confidence intervals of the estimated rate and dates. If the bootstrap trees file is specified, then dating is 
[00;00m	   processed on each of these trees, and the 2.5th and 97.5th percentile of calculated rates and dates are reported as confidence intervals.
[00;00m	   If one of the bootstrap trees does not have the same topology as the original tree, then only confidence intervals of root dates are referred.
[00;00m	   If there's no bootstrap trees, then we simulate a set of trees. In this case, the number of simulated trees should be specified. Those 
[00;00m	   trees have the same topology as the original one, and their branch lengths are generated as follow:
[00;00m	          b_i = Poisson(B_i*seqLen)*lognormal(1,q)
[00;00m	   where B_i is the branch length estimated by lsd2 and q is the standard deviation of relaxed clock settable via option -q.
[00;00m	   So the first term represents a simulation for the number of substitutions on the branch i; and the second term adds the effect of relaxed
[00;00m	   clock on that branch length.
[00;00m	   Confidence intervals are written in the nexus tree with label CI_date, and can be visualzed with Figtree under Node bar feature with CI_height.
[00;00m	[00;01m-g [00;04moutgroupFile
[00;00m	   If your data contain outgroups, then specify the name of the outgroup file here. The program will use the outgroups to root the trees.
[00;00m	   If you use this combined with options -G, then the outgroups will be removed. The format of this file should be:
[00;00m	        n
[00;00m	        OUTGROUP1
[00;00m	        OUTGROUP2
[00;00m	        ...
[00;00m	        OUTGROUPn
[00;00m	[00;01m-F 
[00;00m	   By default without this option, we impose the constraints that the date of every node is equal or smaller then the
[00;00m	   dates of its descendants, so the running time is quasi-linear. Using this option we ignore this temporal constraints, and
[00;00m	   the the running time becomes linear, much faster.
[00;00m	[00;01m-h [00;04mhelp
[00;00m	   Print this message.
[00;00m	[00;01m-i [00;04minputTreesFile
[00;00m	   The name of the input trees file. It contains tree(s) in newick format, each tree on one line. Note that the taxa sets of all
[00;00m	   trees must be the same.
[00;00m	[00;01m-j
[00;00m	   Verbose mode for output messages.
[00;00m	[00;01m-G
[00;00m	   Use this option to remove the outgroups (given in option -g) in the estimated tree. If this option is not used, the outgroups 
[00;00m	   will be kept and the root position in estimated on the branch defined by the outgroups.
[00;00m	[00;01m-l [00;04mnullBlen
[00;00m	   A branch in the input tree is considered informative if its length is greater this value. By default it is 0.5/seq_length. Only 
[00;00m	   informative branches are forced to be bigger than a minimum branch length (see option -u for more information about this).
[00;00m	[00;01m-m [00;04msamplingNumberOutlier
[00;00m	   The number of dated nodes to be sampled when detecting outlier nodes. This should be smaller than the number of dated nodes,
[00;00m	   and is 10 by default.
[00;00m	[00;01m-n [00;04mdatasetNumber
[00;00m	   The number of trees that you want to read and analyse.
[00;00m	[00;01m-o [00;04moutputFile
[00;00m	   The base name of the output files to write the results and the time-scale trees.
[00;00m	[00;01m-p [00;04mpartitionFile
[00;00m	   The file that defines the partition of branches into multiple subsets in the case that you know each subset has a different rate.
[00;00m	   In the partition file, each line contains the name of the group, the prior proportion of the group rate compared to the main rate
[00;00m	   (selecting an appropriate value for this helps to converge faster), and a list of subtrees whose branches are supposed to have the 
[00;00m	   same substitution rate. All branches that are not assigned to any subtree form a group having another rate.
[00;00m	   A subtree is defined between {}: its first node corresponds to the root of the subtree, and the following nodes (if there any) 
[00;00m	   correspond to the tips of the subtree. If the first node is a tip label then it takes the mrca of all tips as the root of the subtree.
[00;00m	   If the tips of the subtree are not defined (so there's only the defined root), then by 
[00;00m	   default this subtree is extended down to the tips of the full tree. For example the input tree is 
[00;00m	   ((A:0.12,D:0.12)n1:0.3,((B:0.3,C:0.5)n2:0.4,(E:0.5,(F:0.2,G:0.3)n3:0.33)n4:0.22)n5:0.2)root;
[00;00m	   and you have the following partition file:
[00;00m	         group1 1 {n1} {n5 n4}
[00;00m	         group2 1 {n3}
[00;00m	   then there are 3 rates: the first one includes the branches (n1,A), (n1,D), (n5,n4), (n5,n2), (n2,B), (n2,C); the second one 
[00;00m	   includes the branches (n3,F), (n3,G), and the last one includes all the remaining branches. If the internal nodes don't have labels,
[00;00m	   then they can be defined by mrca of at least two tips, for example n1 is mrca(A,D)
[00;00m	[00;01m-q [00;04mstandardDeviationRelaxedClock
[00;00m	   This value is involved in calculating confidence intervals to simulate a lognormal relaxed clock. We multiply the simulated branch lengths
[00;00m	   with a lognormal distribution with mean 1, and standard deviation q. By default q is 0.2. The bigger q is, the more your tree is relaxed
[00;00m	   and give you bigger confidence intervals.
[00;00m	[00;01m-r [00;04mrootingMethod
[00;00m	   This option is used to specify the rooting method to estimate the position of the root for unrooted trees, or
[00;00m	   re-estimate the root for rooted trees. The principle is to search for the position of the root that minimizes
[00;00m	   the objective function.
[00;00m	   Use [00;01m-r l[00;00m if your tree is rooted, and you want to re-estimate the root locally around the given root.
[00;00m	   Use [00;01m-r a[00;00m if you want to estimate the root on all branches (ignoring the given root if the tree is rooted).
[00;00m	       In this case, if the constrained mode is chosen (option -c), method "a" first estimates the root without using the constraints.
[00;00m	       After that, it uses the constrained mode to improve locally the position of the root around this pre-estimated root.
[00;00m	   Use [00;01m-r as[00;00m if you want to estimate to root using constrained mode on all branches.
[00;00m	   Use [00;01m-r k[00;00m if you want to re-estimate the root position on the same branche of the given root.
[00;00m	       If combined with option -g, the root will be estimated on the branche defined by the outgroups.
[00;00m	[00;01m-R [00;04mround_time
[00;00m	   This value is used to round the minimum branch length of the time scaled tree. The purpose of this is to make the minimum branch length
[00;00m	   a meaningful time unit, such as day, week, year ... By default this value is 365, so if the input dates are year, the minimum branch
[00;00m	   length is rounded to day. The rounding formula is round(R*minblen)/R.
[00;00m	[00;01m-s [00;04msequenceLength
[00;00m	   This option is used to specify the sequence length when estimating confidence intervals (option -f). It is used to generate 
[00;00m	   integer branch lengths (number of substitutions) by multiplying this with the estimated branch lengths. By default it is 1000.
[00;00m	[00;01m-S [00;04mminSupport
[00;00m	   Together with collapsing internal short branches (see option -l), users can also collapse internal branches having weak support values (if
[00;00m	   provided in the input tree) by using this option. The program will collapse all internal branches having support <= the specifed value.
[00;00m	[00;01m-t [00;04mrateLowerBound
[00;00m	   This option corresponds to the lower bound for the estimating rate. It is 1e-10 by default.
[00;00m	[00;01m-u [00;04mminBlen
[00;00m	   Using this option, lsd2 forces every branch of the time scaled tree to be >= minBlen. minBlen is either a positive real or letter e. 
[00;00m	   For the later case lsd2 estimates a minimum branch length, which is m/rate (m is the minimum branch length of the input tree, and 
[00;00m	   rate is an pre-estimated rate). This estimated value is then rounded to the number of days or weeks or years, using the rounding
[00;00m	   parameter -R. Without this option minBlen = 0 by default.
[00;00m	[00;01m-U [00;04mminExBlen
[00;00m	   Similar to option -u but applies for external branches if specified. If it's not specified then the minimum branch length of external
[00;00m	   branches is set the same as the one of internal branch.
[00;00m	[00;01m-v [00;04mvariance
[00;00m	   Use this option to specify the way you want to apply variances for the branch lengths. Variances are used to recompense big errors on
[00;00m	   long estimated branch lengths. The variance of the branch Bi is Vi = (Bi+b) where b is specified by option -b.
[00;00m	   If [00;00m[00;04mvariance[00;00m=0, then we don't use variance. If [00;00m[00;04mvariance[00;00m=1, then LSD uses the input branch lengths to calculate variances.
[00;00m	   If [00;00m[00;04mvariance[00;00m=2, then LSD runs twice where the second time it calculates the variances based on the estimated branch
[00;00m	   lengths of the first run. By default [00;00m[00;04mvariance[00;00m=1.
[00;00m	[00;01m-V 
[00;00m	   Get the actual version.
[00;00m	[00;01m-w [00;04mgivenRte
[00;00m	   This option is used to specify the name of the file containing the substitution rates.
[00;00m	   In this case, the program will use the given rates to estimate the dates of the nodes.
[00;00m	   This file should have the following format
[00;00m	        RATE1
[00;00m	        RATE2
[00;00m	        ...
[00;00m	  where RATEi is the rate of the tree i in the inputTreesFile.
[00;00m	[00;01m-z [00;04mtipsDate
[00;00m	   To specify the tips date if they are all equal. If the tips date is not a number, but a string (ex: 2020-01-10, or b(2019,2020))
[00;00m	   then it should be put between the quotes.
